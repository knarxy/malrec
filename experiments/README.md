# Experiments

Each of these answers one question with a measurement, and the answer is why
the production code looks the way it does. They run against the live dev
database and print a table; none of them are imported by the package.

```bash
set -a && . ../.env && set +a
../.venv/bin/python exp_implicit.py
```

Protocol throughout: temporal holdout at 8 sizes (25…60), reporting mean
Spearman / nDCG@10 / RMSE **and the per-split win count**, so a lucky average
is visible as such. Random K-fold is never used — it lets the model train on
2026 ratings to predict a 2018 one.

| script | question | verdict |
|---|---|---|
| `exp_implicit.py` | Does the unscored half of a list carry signal? | **kept** — ρ 0.756 → 0.769, nDCG 0.797 → 0.810, 7/8 splits |
| `exp_rank.py` | Is a ranking objective better than score regression? | **rejected** — pairwise ρ 0.730, LambdaMART 0.547, vs ridge 0.778; lost every split |
| `exp_embed.py` | Do synopsis embeddings add anything over AniList tags? | **rejected** — kNN feature ±0.003, SVD columns −0.05 to −0.15 |

`exp_embed.py` needs `pip install model2vec`, which is deliberately not a
project dependency since the result was negative.

## Notes on the negative results

**Ranking objectives lose because of sample size, not principle.** A pairwise
model has to learn from ~10k pairs generated by ~180 rows; the pairs are not
independent, so the effective sample is still ~180 while the variance is much
higher. Ridge's shrinkage is worth more here than optimising the right loss.
The trend was monotonic — the more regularised the pairwise model, the closer
it got to ridge without ever passing it. Worth revisiting at a few thousand
ratings, not before.

**Embeddings lose because tags already won.** AniList's ~22 weighted tags per
anime are human-curated and describe premise directly ("Time Manipulation",
"Death Game", "Primarily Adult Cast"). A synopsis embedding is a noisier route
to the same information, and 48 extra dense columns on ~180 training rows cost
far more in variance than they return.
